- 恢复唯一的 Semantic Memory 专用 MCP 注册，与其他普通 memory/codebase 工具分开。

- CMD 使用 CRLF、ASCII 控制文本、引号路径和真实退出码，避免命令截断及错误成功提示。
- 整理新包的全新安装、同版本修复与受管理升级路径；保留版本、配置和插件恢复依据。

旧 codebase_memory stderr 适配属于原机器的独立兼容修复。本通用包不改写其他 MCP，不附带发布者的 codebase、provider 或身份配置。

## 限制

- 精确基线兼容补丁，不是本轮完整源码构建；没有逐字节可复现构建证明。
- EXE 未新增签名；另一台电脑的信任、重启、GUI/DPI、长内容和真实使用链仍需验收。

- 内容检测器未全面重写；不能根据有限拒绝测试宣称识别所有凭据格式。
- 有界 canary/演化/维护保留授权限制，默认 static embedding、automatic maintenance=0。
- 已保存的新知识仍可为 candidate；自报告 feedback 保持 shadow reward，不伪造确认或成功使用。

公开包、仓库和验收摘要不包含本机私人库、当前用户路径、任务历史、完整反馈 payload 或凭据。上游公开测试中的固定 fixture 名称作为历史测试保留。安装时在使用者机器产生的备份归使用者保存。
