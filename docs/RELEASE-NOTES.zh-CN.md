# R5 发布记录

版本：`1.1.0-rc.1+codex.20261005112500`，Windows x64；原生 `v1.1.0-rc.1`，全局兼容核心 r2。R5 是公开分发与安装器修订，原生核心 SHA 保持本机已验收版本。

## 修复

- 恢复唯一的 Semantic Memory 专用 MCP 注册，与其他普通 memory/codebase 工具分开。
- Hook 明确使用 UTF-8，保留有界 Stop 与 fail-open。
- 移除正常项目名称校验中的旧机器白名单，并允许已有全局来源上下文的 events/global。
- 反馈调用文档纠正 model_self_report 与 evidence_source=model 的匹配要求。
- CMD 使用 CRLF、ASCII 控制文本、引号路径和真实退出码，避免命令截断及错误成功提示。
- 整理新包的全新安装、同版本修复与受管理升级路径；保留版本、配置和插件恢复依据。

旧 codebase_memory stderr 适配属于原机器的独立兼容修复。本通用包不改写其他 MCP，不附带发布者的 codebase、provider 或身份配置。

## 已有本机证据（2026-10-05）

当前 Codex 聊天实际加载专用工具；global events 写入合法偏好；两个不同实际工作区召回同一条全局记录；真实历史 feedback 精确重放保持 1 条；任务收尾 recorded/OK 后 status=completed；正式 memory/graph quick_check=ok。候选捕获和召回成功，没有宣称晋升或启用自动演化。

兼容核心隔离功能 21 项、回滚补验 6 项、CMD 路径/成功/失败/依赖及真实入口 10 项通过。这些对应兼容核心与入口修订，不替代新公开包的隔离安装验收。新包验收摘要见 `ACCEPTANCE.json`。

本次公开包从 ZIP 解压后通过 8 项完整安装与跨工作区测试；原始 R4 到 R5 的升级、损坏插件包拒绝和失败恢复通过 9 项测试；升级回退、全新卸载与数据保留通过 9 项测试。测试使用隔离用户/配置/数据目录，未向发布者正式记忆库写入测试记录。最终打包收尾仅补充文档和验收摘要，安装器及原生 EXE 与上述受测版本一致。

自定义 ASCII 根目录另通过 5 项插件 Hook 检查：选择该根的运行时、调用成功、生命周期写入正确数据根、数据库完整性及未创建中文 LocalAppData 下的备用运行时。自定义根需要一次性设置当前用户的 `SEMANTIC_MEMORY_HOME` 并在重新登录 Windows 后打开 Codex，具体步骤及撤销方法见安装文档；安装器不隐式修改用户环境变量。

## 限制

- 精确基线兼容补丁，不是本轮完整源码构建；没有逐字节可复现构建证明。
- EXE 未新增签名；另一台电脑的信任、重启、GUI/DPI、长内容和真实使用链仍需验收。
- 中文工作区可用；当前原生 r2 不支持非 ASCII 安装根。安装器在写入前拒绝并提示自定义 ASCII 根目录，避免产生乱码数据目录。该限制尚未通过完整核心重建解决。
- 内容检测器未全面重写；不能根据有限拒绝测试宣称识别所有凭据格式。
- 有界 canary/演化/维护保留授权限制，默认 static embedding、automatic maintenance=0。
- 已保存的新知识仍可为 candidate；自报告 feedback 保持 shadow reward，不伪造确认或成功使用。

公开包、仓库和验收摘要不包含本机私人库、当前用户路径、任务历史、完整反馈 payload 或凭据。上游公开测试中的固定 fixture 名称作为历史测试保留。安装时在使用者机器产生的备份归使用者保存。
